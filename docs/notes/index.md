# 단편 노트

**문제 하나를 문서 한 장으로 끝낸 기록**입니다. 연도 폴더 아래에 쌓입니다.

기술 리서치가 "이 기술을 이해한다"라면, 단편 노트는 "이 문제를 겪었고 이렇게 해결했다"입니다.
깊이 팔 계획이 아직 없거나, 여러 기술에 걸쳐 있어 한 폴더에 넣기 애매한 것들이 여기로 옵니다.

## 무엇을 남기는가

- 실무에서 막혔던 문제와 그 원인 — **증상이 아니라 원인**까지 도달한 것만
- 문서를 읽다 알게 된 사실 중 나중에 다시 찾을 만한 것
- "왜 이렇게 되지?" 하고 직접 확인해 본 실험

## 승격 규칙

같은 기술에 대한 노트가 **3편 이상 쌓이면** 그 기술은 [기술 리서치](../topics/index.md)의 폴더로 승격시킵니다.
세 번 찾아봤다는 건 이미 깊이 팔 이유가 생겼다는 뜻이기 때문입니다.
승격할 땐 기존 노트의 내용을 새 폴더의 해당 파일로 옮기고, 노트는 지웁니다 — 같은 내용이 두 곳에 남지 않게 합니다.
