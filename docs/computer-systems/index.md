# 컴퓨터 시스템

프로그램이 하드웨어를 직접 다루지 않고도 실행될 수 있도록 컴퓨터의 층과 경계를 다룹니다.

## 다루는 것

- 운영체제 — 프로그램과 하드웨어 사이에서 자원과 실행 환경을 제공하는 소프트웨어
- 커널 — 운영체제에서 CPU·메모리·프로세스·장치 접근을 관리하는 핵심 부분
- POSIX — 운영체제가 응용 프로그램에 제공하는 공통 인터페이스와 실행 환경의 표준

## 어디로 가는가

- **프로그래밍 언어 자체**는 [언어](../languages/index.md)로 갑니다.
- **애플리케이션 서버와 런타임**은 [백엔드](../backend/index.md)로 갑니다.
- **컨테이너·클라우드·관측성처럼 운영 환경을 구성하는 도구**는 [인프라](../infrastructure/index.md)로 갑니다.
