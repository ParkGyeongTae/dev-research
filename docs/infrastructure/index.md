# 인프라

**애플리케이션이 실제로 올라가 도는 바닥**을 다룹니다.

## 다루는 것

- 컨테이너와 오케스트레이션 — Docker, Kubernetes
- IaC — Terraform 등 인프라를 코드로 다루는 도구
- 클라우드 서비스의 동작과 과금 구조
- 관측성 — Prometheus, 로그·메트릭·트레이스
- 네트워크·리눅스 — 위 도구를 이해하는 데 필요한 만큼

## 경계

- **그 위에서 도는 애플리케이션 코드**는 [백엔드](../backend/index.md)로 갑니다.
- **데이터 처리 엔진 자체의 동작**은 [데이터 엔지니어링](../data-engineering/index.md)으로 갑니다. Kubernetes 위의 Spark라면, 스케줄링·리소스 배분은 여기, 셔플·실행 계획은 그쪽입니다.
