# 개념 정리

**특정 제품에 종속되지 않는 이론과 개념**입니다.

Kafka의 파티션은 Kafka 폴더에 씁니다. 하지만 "분산 시스템에서 순서 보장이 왜 어려운가"는
Kafka에도, 데이터베이스 복제에도, 메시지 큐에도 걸립니다 — 그런 것이 여기로 옵니다.

## 여기 올라오는 기준

**두 곳 이상의 문서에서 인용될 때만** 개념 정리로 올립니다.
한 기술에서만 쓰는 개념은 그 기술 폴더의 `03_concepts.md`에 둡니다.
미리 만들어 두지 않고, 두 번째 인용이 생기는 순간 옮깁니다.
