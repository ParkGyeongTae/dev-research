# 개발 리서치 노트

현업에서 **데이터 엔지니어링**을 하면서 마주친 기술을, 쓸 줄 아는 수준에서 멈추지 않고
**왜 그렇게 동작하는지까지** 정리해 두는 개인 학습 아카이브입니다.

데이터 엔지니어링을 중심에 두되 언어·백엔드·프론트엔드·정적 사이트 생성기·인프라·데이터베이스·LLM까지 개발 전반을 다룹니다.
읽고 끝나는 글이 아니라, 나중에 같은 문제를 만났을 때 **다시 찾아와 답을 얻는 문서**를 목표로 합니다.
