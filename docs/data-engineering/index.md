# 데이터 엔지니어링

**데이터를 옮기고, 바꾸고, 쌓는 파이프라인**을 다룹니다. 이 저장소에서 가장 두껍게 채울 영역입니다.

## 다루는 것

- 스트리밍 — Kafka, Flink 등 메시지가 흐르는 구조
- 배치 처리 — Spark 등 대량 데이터를 나눠 처리하는 엔진
- 오케스트레이션 — Airflow 등 작업 간 의존과 재실행
- 저장 포맷과 테이블 포맷 — Parquet, Iceberg, Delta
- CDC·수집 — 원천에서 데이터를 빼내 오는 방식

## 경계

- **저장 엔진 자체의 내부 동작**(인덱스, 트랜잭션, 쿼리 실행)은 [데이터베이스](../database/index.md)로 갑니다. 같은 제품이라도 "파이프라인에서 어떻게 쓰는가"는 여기, "안에서 어떻게 동작하는가"는 그쪽입니다.
- **클러스터를 어떻게 띄우고 운영하는가**는 [인프라](../infrastructure/index.md)로 갑니다.
- **쌓은 데이터로 무엇을 알아내는가**는 [데이터 분석](../data-analytics/index.md)으로 갑니다.
