# 정적 사이트 생성기

**문서와 콘텐츠를 정적 웹사이트로 빌드하는 도구**를 다룹니다. 문서 구조·테마·검색·사이트 빌드처럼 정적 사이트 생성기 자체의 동작과 사용법이 주제입니다.

## 다루는 것

- 문서 사이트 생성기 — VitePress, MkDocs, Docusaurus
- 정적 빌드 — 소스 문서가 HTML·CSS·JavaScript 산출물로 바뀌는 과정
- 문서 사이트 기능 — 내비게이션, 테마, 검색, 코드 하이라이팅
- 여러 생성기에 공통인 선택 기준과 동작 차이

## 어디로 가는가

- **브라우저 애플리케이션의 UI 프레임워크·번들러·렌더링**은 [프론트엔드](../frontend/index.md)로 갑니다. 여기서는 문서·콘텐츠를 사이트로 만드는 도구를 다룹니다.
- **사이트를 어디에 배포하고 어떻게 운영하는가**는 [인프라](../infrastructure/index.md)로 갑니다. 여기서는 정적 사이트 생성기의 빌드 결과를 다루는 범위까지만 다룹니다.
- **JavaScript·TypeScript·Python 언어 자체**는 [언어](../languages/index.md)로 갑니다. 생성기를 구현한 언어가 아니라 생성기라는 도구가 주제입니다.
