# AGENTS.md — 에이전트 지침을 두는 공개 Markdown 포맷
> **원문** [AGENTS.md](https://agents.md/)

## 실행 환경

- OS: macOS 15.7.4, 빌드 24G517 (`sw_vers`로 확인)
- 실행 위치: 이 저장소 루트

## 무엇을 정하는 포맷인가

> A simple, open format for guiding coding agents.
>
> **번역** — 코딩 에이전트를 안내하는 단순한 공개 포맷입니다.
>
> — [AGENTS.md](https://agents.md/)

README가 사람에게 프로젝트를 소개한다면, AGENTS.md는 에이전트에게 빌드·테스트·작업 규칙을 전달하는 자리입니다. 원문 FAQ에 따르면 일반 Markdown이며 필수 필드와 정해진 제목은 없습니다. **필수 필드가 없다는 사실만으로 스키마·린터가 전혀 없다고 결론 내릴 수는 없습니다.**

— [AGENTS.md — Why AGENTS.md? / FAQ](https://agents.md/)

이 저장소에 맞춘 최소 작성 예시입니다. 명령뿐 아니라 실행할 조건도 적었습니다.

```markdown title="AGENTS.md 작성 예시"
# AGENTS.md

## 문서 수정
- 본문은 한국어 존댓말로 작성합니다.
- 문서를 수정한 뒤 저장소 루트에서 `npm run build`를 실행합니다.
```

**작성 판단:** 명령 이름만 적기보다 작업 디렉터리와 실행 조건을 함께 적으면, 에이전트가 적용 범위를 판단할 때 필요한 정보를 줄 수 있습니다.

## 중첩 지침의 우선순위는 무엇을 뜻하는가

원문은 루트에 파일을 만들고, 모노레포에서는 패키지별로 추가하도록 안내합니다. 충돌 FAQ의 표현은 다음과 같습니다.

> The closest AGENTS.md to the edited file wins;
>
> **번역** — 편집하는 파일에 가장 가까운 AGENTS.md가 우선합니다.
>
> — [AGENTS.md — FAQ](https://agents.md/)

예를 들어 루트 지침에 “작은따옴표 사용”, `packages/api/AGENTS.md`에 “큰따옴표 사용”을 적었다면, 원문의 충돌 규칙상 `packages/api/handler.ts`에는 큰따옴표 지침이 우선합니다. FAQ는 명시적인 사용자 채팅 지시가 우선한다고도 설명합니다.

— [AGENTS.md — How to use AGENTS.md? / FAQ](https://agents.md/)

**해석의 한계:** 이는 충돌 시 우선순위에 관한 설명입니다. 하위 파일이 있으면 상위 파일 전체를 버린다는 뜻으로 확대할 근거는 없습니다. 실제 탐색·병합 방식은 사용할 도구에서 별도로 확인해야 합니다.

## 적어 둔 명령은 어떻게 취급되는가

원문 FAQ는 관련 프로그램 검사를 실행하고 실패를 수정하려 시도한다고 설명합니다. 이는 **테스트 명령에 대한 안내**이며, 배포·마이그레이션 명령까지 자동 실행한다는 근거는 아닙니다.

— [AGENTS.md — FAQ](https://agents.md/)

**작성 판단:** 위 예시처럼 “문서 수정 후 빌드”라고 적용 조건을 적고, 실패했을 때 무엇을 확인할지도 프로젝트에 맞게 덧붙이는 편이 좋습니다. 이 문서에서는 에이전트가 예시 지침을 읽고 자동 실행하는 실험은 하지 않았습니다.

## 기존 파일은 어떻게 연결하는가

원문은 기존 파일을 AGENTS.md로 옮긴 뒤 이전 이름에 심볼릭 링크를 만드는 방법을 안내합니다. 다음은 이 저장소의 파일 연결을 이번에 직접 확인한 기록입니다.

— [AGENTS.md — How do I migrate existing docs to AGENTS.md?](https://agents.md/)

```console
$ ls -l CLAUDE.md
lrwxr-xr-x  1 pgt0409  staff  9 Oct 24 16:21 CLAUDE.md -> AGENTS.md
$ readlink CLAUDE.md
AGENTS.md
```

**직접 확인한 것:** `CLAUDE.md`는 `AGENTS.md`를 가리키는 심볼릭 링크입니다. 따라서 이 저장소의 지침을 고칠 때는 대상 파일인 `AGENTS.md`를 편집합니다. 이 출력은 파일 연결의 증거이며, 특정 에이전트가 지침을 로드했다는 증거는 아닙니다.

## 확인하지 못한 것

- **도구별 탐색·병합·크기 한도 — 확인 필요:** 원문만으로 각 구현을 확정할 수 없으며 도구별 대조는 하지 않았습니다.
- **검사 명령의 자동 실행 — 미실행:** 별도 에이전트 세션에서 지침 로드와 실행 과정을 재현하지 않았습니다.
- **채택 규모와 준수율 — 확인 필요:** 원문의 프로젝트 수를 독립 집계하거나 지침 준수 여부를 측정하지 않았습니다.
