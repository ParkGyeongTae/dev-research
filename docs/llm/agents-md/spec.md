# AGENTS.md — 지침의 내용과 도구의 로드 규칙을 구분해야 합니다
> 원문: [AGENTS.md](https://agents.md/)

## 실행 환경

- OS: macOS 15.7.4, 빌드 24G517 (`sw_vers`로 이번에 확인)
- 실행 위치: 이 저장소 루트
- 도구: macOS의 `ls`, `readlink` 사용. 개별 도구 버전은 확인하지 않았습니다.
- Codex 부분은 공식 문서 확인이며 별도 세션 실행은 하지 않았습니다.

## 무엇을 정하고 무엇을 구현에 맡기는가

> A simple, open format for guiding coding agents.
>
> **번역** — 코딩 에이전트를 안내하는 단순한 공개 포맷입니다.
>
> — [AGENTS.md](https://agents.md/)

AGENTS.md는 빌드·테스트·작업 규칙을 에이전트에게 전달하는 Markdown 파일입니다. 사람을 위한 README를 보완하도록 설계됐으며, 필수 필드나 정해진 제목은 없습니다. 아래의 `문서 수정`도 예약된 키가 아니라 지침을 묶는 제목입니다. 원문에는 판번호가 없어 제목과 URL을 기준으로 확인했습니다. — [AGENTS.md — Why AGENTS.md? / FAQ](https://agents.md/)

```markdown title="이 저장소에 맞춘 최소 예시"
# AGENTS.md

## 문서 수정
- docs/ 문서는 한국어 존댓말로 작성합니다.
- 문서를 수정한 뒤 저장소 루트에서 `npm run build`를 실행합니다.
- 검사를 실행하지 못하면 완료 보고에 이유를 적습니다.
```

**작성 판단:** 대상(`docs/`), 행동(작성·빌드), 실행 위치(루트), 미실행 시 보고를 함께 적었습니다. 명령만 나열했을 때 생기는 “어디에서, 언제 실행하는가”의 공백을 줄이려는 작성안입니다. 이 예시의 에이전트 준수율 측정은 **미실행**입니다.

**해석의 경계:** 자유로운 Markdown이라는 사실은 모든 도구가 같은 파일을 같은 시점에 읽는다는 뜻이 아닙니다. 필수 필드가 없다는 사실만으로 별도의 스키마·린터가 전혀 없다고 결론 내리지도 않습니다. 포맷의 충돌 규칙과 도구의 탐색 규칙을 나눠 확인해야 합니다.

## 중첩 파일은 충돌하는 규칙을 어떻게 좁히는가

공식 사이트는 루트 파일과 패키지별 중첩 파일을 안내하고, 충돌하면 편집 파일에 가장 가까운 AGENTS.md를 우선한다고 설명합니다. 명시적인 사용자 채팅 지시도 저장소 지침보다 우선한다고 안내합니다. 이를 하위 파일이 상위 파일 전체를 폐기한다는 뜻으로 확대하지는 않습니다. — [AGENTS.md — How to use AGENTS.md? / FAQ](https://agents.md/)

다음은 충돌과 공존을 구분하기 위한 **가상 예시**입니다. 두 파일을 모두 읽은 도구가 위 충돌 규칙을 적용한다고 가정합니다.

```text
repo/
├── AGENTS.md                  # 테스트를 실행합니다. 문자열은 작은따옴표를 씁니다.
└── packages/
    └── api/
        ├── AGENTS.md          # 문자열은 큰따옴표를 씁니다.
        └── handler.ts
```

| `handler.ts`에 관한 판단 | 이유 |
| --- | --- |
| 큰따옴표를 사용합니다. | 같은 항목에 대한 충돌을 하위 지침으로 해결합니다. |
| 테스트 지침도 적용 대상으로 봅니다. | 따옴표 지침과 충돌하지 않습니다. |
| 두 파일이 실제로 로드됐는지는 별도로 확인합니다. | 우선순위 설명만으로 탐색 성공을 증명할 수 없습니다. |

**실무 판단:** 따옴표가 예상과 다르면 규칙을 더 강하게 쓰기 전에 하위 파일의 로드 여부와 같은 항목을 덮어쓰는 지침을 확인합니다. 위 표는 충돌 규칙의 적용 예시이며 실제 에이전트 실행 결과가 아닙니다.

## Codex에서는 왜 작업 디렉터리도 확인해야 하는가

Codex 공식 안내는 실행 시작 시 지침 체인을 만들며, 프로젝트 루트에서 **현재 작업 디렉터리까지** 탐색한다고 설명합니다. 프로젝트 루트를 찾지 못하면 현재 디렉터리만 확인합니다. 디렉터리마다 `AGENTS.override.md`, `AGENTS.md`, 설정한 대체 파일명 순으로 최대 하나를 선택하고 상위에서 하위 순으로 합칩니다. 전역 지침은 Codex home에서 별도로 찾습니다. 이는 포맷 공통 규격이 아니라 **Codex의 문서상 동작**입니다. 해당 안내에는 제품 판번호가 없습니다. — [Custom instructions with AGENTS.md — How Codex discovers guidance](https://learn.chatgpt.com/docs/agent-configuration/agents-md#how-codex-discovers-guidance)

위 가상 저장소에서 시작 위치를 바꾸는 예시입니다. **미실행**이며 예상은 공식 안내의 시작 시 탐색 범위에 한정합니다.

```bash title="가상 저장소 repo/에서 실행하는 비교 예시"
codex "로드한 지침 파일을 나열해 주세요."
codex --cd packages/api "로드한 지침 파일을 나열해 주세요."
```

첫 명령의 시작 시 탐색 경로에는 `packages/api/`가 없습니다. 둘째는 그 디렉터리까지 탐색합니다. 같은 디렉터리에 override 파일이 있다면 일반 AGENTS.md와 둘 다 선택되는 것도 아닙니다. “편집할 파일에 가장 가깝다”와 “시작 시 탐색해서 포함했다”를 구분해야 합니다. 이후의 추가 파일 읽기까지 이 설명으로 단정하지 않습니다. — [Custom instructions with AGENTS.md — Layer project instructions](https://learn.chatgpt.com/docs/agent-configuration/agents-md#layer-project-instructions)

문서상 합산 크기 한도 `project_doc_max_bytes`의 기본값은 **32 KiB**입니다. 이 세션의 실제 설정값을 확인한 것은 아닙니다. 지침이 누락되거나 오래된 것처럼 보이면 탐색 경로·override·크기 한도와 재시작 여부를 확인하도록 공식 안내가 권합니다. — [Custom instructions with AGENTS.md — Troubleshoot discovery issues](https://learn.chatgpt.com/docs/agent-configuration/agents-md#troubleshoot-discovery-issues)

## 검사 명령을 적으면 실행이 보장되는가

원문 FAQ는 관련 검사를 실행하고 실패를 고치려 시도한다고 안내합니다. “시도”는 검사 성공의 보장과 다르며, 이를 배포·마이그레이션 명령까지 자동 실행한다는 근거로 삼지는 않습니다. — [AGENTS.md — FAQ](https://agents.md/)

**실무 판단:** 최소 예시의 `npm run build`에 대해서는 다음 증거를 나눠 봅니다.

| 확인 단계 | 확인할 증거 | 그 증거만으로 알 수 없는 것 |
| --- | --- | --- |
| 파일이 존재합니다. | 파일 내용·경로 | 에이전트가 실제로 읽었는지 |
| 명령을 실행했습니다. | 명령·작업 디렉터리·실제 출력 | 성공했는지, 올바른 대상을 검사했는지 |
| 검사가 통과했습니다. | 종료 코드·검사 범위 | 검사하지 않는 규칙까지 지켰는지 |

예를 들어 빌드가 성공해도 “본문을 존댓말로 썼다”는 별도 검토가 필요합니다. **이 저장소의 판단:** 실행 불가와 검사 실패를 성공으로 요약하지 않고 무엇을 확인했는지 보고합니다.

## 기존 지침 파일을 한 원본에 연결하려면

공식 사이트는 기존 파일을 AGENTS.md로 옮기고 이전 이름에 심볼릭 링크를 두는 마이그레이션 예시를 제공합니다. — [AGENTS.md — How do I migrate existing docs to AGENTS.md?](https://agents.md/)

**기존 기록(과거 관측):** 이전 문서의 링크 확인 출력입니다. 현재 실행 결과와 구분해 보존합니다.

```console
$ ls -l CLAUDE.md
lrwxr-xr-x  1 pgt0409  staff  9 Oct 24 16:21 CLAUDE.md -> AGENTS.md
$ readlink CLAUDE.md
AGENTS.md
```

**이번 실행:** 루트 지침에서 원본을 공유한다고 정한 두 파일을 다시 확인했습니다.

```console
$ readlink CLAUDE.md
AGENTS.md
$ readlink README.md
AGENTS.md
```

**직접 확인한 것:** 두 이름 모두 `AGENTS.md`를 가리키는 심볼릭 링크입니다. 이 저장소에서는 대상인 AGENTS.md가 원본이며, 이는 이 저장소의 선택입니다. 모든 프로젝트가 README까지 연결해야 한다는 포맷 규칙은 아닙니다. 링크 출력은 파일 연결의 증거이며 특정 에이전트의 로드 성공 증거는 아닙니다.

## 확인하지 못한 것

- **도구별 실제 탐색·병합 — 미실행:** Codex 공식 안내를 읽었지만 별도 세션에서 가상 저장소의 시작 위치·override·크기 한도를 비교하지 않았습니다. 다른 에이전트 구현과의 대조도 하지 않았습니다.
- **검사 명령 자동 실행·준수율 — 미실행:** 지침을 주입한 별도 에이전트의 행동을 측정하지 않았습니다. 이 문서의 로컬 명령은 링크와 환경을 확인한 기록입니다.
- **채택 규모 — 확인 필요:** 공식 사이트의 프로젝트 수를 독립 집계하지 않았습니다. 채택 수를 준수율의 근거로 사용하지 않습니다.
