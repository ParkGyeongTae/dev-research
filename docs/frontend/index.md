# 프론트엔드

**브라우저에서 실행되는 쪽**을 다룹니다.

## 다루는 것

- UI 프레임워크와 상태 관리 — React 등
- 언어·타입 시스템 — TypeScript
- 빌드 도구와 번들러 — 무엇이 왜 느려지는가
- 브라우저의 동작 — 렌더링 경로, 네트워크 요청, 캐시

## 경계

- **서버가 무엇을 내려주는가**는 [백엔드](../backend/index.md)로 갑니다.
- **차트를 어떻게 그릴 것인가**가 아니라 **무엇을 보여줄 것인가**가 주제라면 [데이터 분석](../data-analytics/index.md)이 맞습니다.
