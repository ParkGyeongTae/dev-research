# 데이터 분석

**쌓인 데이터에서 답을 꺼내는 쪽**을 다룹니다.

## 다루는 것

- 분석용 변환 — dbt 등 SQL 기반 모델링
- 분석 라이브러리 — pandas, Polars, DuckDB
- BI·시각화 도구와 지표 정의
- 통계와 실험 설계 — 지표를 잘못 읽는 지점

## 경계

- **데이터를 어떻게 실어 나르는가**는 [데이터 엔지니어링](../data-engineering/index.md)으로 갑니다. 같은 dbt라도 "스케줄러에 물려 돌리는 방법"은 그쪽, "모델을 어떻게 나누는가"는 여기입니다.
- **쿼리가 왜 느린가**가 실행 계획·스토리지 수준의 이야기면 [데이터베이스](../database/index.md)로 갑니다.
