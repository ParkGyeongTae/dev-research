# 데이터베이스

**데이터를 저장하고 꺼내는 엔진의 내부 동작**을 다룹니다. 쓰는 법이 아니라 **왜 그렇게 동작하는가**가 주제입니다.

## 다루는 것

- 관계형 데이터베이스 — PostgreSQL, MySQL의 실행 계획·인덱스·트랜잭션
- 분석용 데이터베이스 — ClickHouse 등 컬럼 지향 엔진
- 키-값·캐시 — Redis
- 공통 주제 — 격리 수준, WAL, 복제, 파티셔닝

## 경계

- **파이프라인에서 원천이나 싱크로 쓰는 방법**은 [데이터 엔지니어링](../data-engineering/index.md)으로 갑니다.
- **애플리케이션에서 어떻게 연결하고 트랜잭션 경계를 어디에 두는가**는 [백엔드](../backend/index.md)로 갑니다.
